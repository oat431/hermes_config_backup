# LinkedIn Profile Audit Checklist

## Scoring Rubric (100 points total)

### 1. Headline (20 points)
- [ ] Custom headline (not default job title)
- [ ] 220 characters maximum (LinkedIn limit)
- [ ] Opens with role title ("Software Engineer", "Full Stack Developer")
- [ ] Includes 3-5 top technologies (Java Spring Boot, ReactJS, Golang)
- [ ] Includes architecture keywords (Microservices, GitOps, Platform Engineering)
- [ ] Signals availability if job-seeking ("Open to New Opportunities")
- [ ] Keywords match recruiter search terms

**Example:**
> Software Engineer (Full Stack) | Java Spring Boot · NestJS · ReactJS · Golang | Microservices & GitOps | Open to New Opportunities

**Scoring:** 20 = perfect headline, 15 = good but missing keywords, 10 = generic job title only, 5 = default or missing

### 2. About Section (20 points)
- [ ] First 3 lines are compelling (shown before "see more" click)
- [ ] Opens with achievement or value proposition (not "I am...")
- [ ] Includes quantifiable achievements in first paragraph
- [ ] Has clear sections: What I Do, Tech Stack, What I'm Looking For
- [ ] Tech stack is a keyword goldmine (helps LinkedIn algorithm)
- [ ] Signals availability if job-seeking
- [ ] Includes contact info at bottom (email, GitHub)
- [ ] 300-500 words (not too short, not a novel)

**First 3 lines example:**
```
Full-stack software engineer with 2+ years of experience building scalable 
microservices platforms at Gosoft (Thailand) and interning at Agoda. I specialize 
in modernizing legacy systems and delivering production-grade applications.
```

**Scoring:** 20 = excellent About section, 15 = good but weak opening, 10 = generic, 5 = missing or minimal

### 3. Experience Section (20 points)
- [ ] All relevant positions listed with complete details
- [ ] Each entry has: company, title, dates, location
- [ ] Each bullet follows [Action] + [What] + [Measurable Outcome] pattern
- [ ] Metrics present in every bullet (same as resume)
- [ ] Skills added to each experience entry (LinkedIn feature)
- [ ] Achievements ranked by impact (most impressive first)
- [ ] More detail than resume (LinkedIn has no page limit)

**Scoring:** 20 = fully detailed with metrics, 15 = some detail but weak metrics, 10 = job descriptions only, 5 = minimal

### 4. Language Proficiency (10 points)
- [ ] All languages listed with correct proficiency levels
- [ ] Native languages marked as "Native or bilingual proficiency" (not lower)
- [ ] Second languages accurately rated based on test scores or experience
- [ ] English proficiency matches actual ability (not underrated)

**Common mistake:** Native speakers often mark their mother tongue as "Professional working proficiency" — this signals to recruiters that they're NOT native speakers.

**Correct levels:**
- Mother tongue → "Native or bilingual proficiency"
- CMU-eGrad B2 or IELTS 6.5+ → "Professional working proficiency"
- Basic conversational → "Limited working proficiency"

**Scoring:** 10 = all levels correct, 7 = minor underrating, 4 = significantly wrong levels, 2 = missing languages

### 5. Open to Work Settings (10 points)
- [ ] "Open to Work" enabled if job-seeking
- [ ] Set to "Recruiters only" (not public green banner) to avoid alerting current employer
- [ ] Job titles specified (Software Engineer, Full Stack Developer, etc.)
- [ ] Locations specified (Bangkok, Remote, etc.)
- [ ] Job types specified (Full-time, Contract, etc.)

**Scoring:** 10 = properly configured, 5 = enabled but incomplete, 0 = not enabled when job-seeking

### 6. Skills Section (10 points)
- [ ] 10-20 relevant skills listed
- [ ] Skills match experience section keywords
- [ ] Top skills endorsed by connections
- [ ] Skills relevant to target role
- [ ] No outdated or irrelevant skills

**Scoring:** 10 = well-curated and endorsed, 7 = good but needs pruning, 4 = disorganized, 2 = missing or irrelevant

### 7. Projects (5 points)
- [ ] 2-4 strong projects listed (not 10+ including trivial ones)
- [ ] Each project has: description, tech stack, impact, GitHub link
- [ ] Projects are interview-worthy (would demo them)
- [ ] Descriptions are professional (not "I just tried to learn...")

**Scoring:** 5 = curated and professional, 3 = good but needs pruning, 1 = bloated with trivial projects

### 8. Additional Sections (5 points)
- [ ] Certifications listed and relevant
- [ ] Test scores included if strong (remove weak scores)
- [ ] Volunteer experience polished professionally
- [ ] Education complete with GPA if recent graduate
- [ ] Honors/awards included

**Scoring:** 5 = all sections polished, 3 = some sections weak, 1 = missing or incomplete

## Critical Red Flags

- ❌ No custom headline (using default job title)
- ❌ About section opens with "I am a..." or personality traits
- ❌ Experience section has no metrics or impact
- ❌ Language levels are wrong (native speaker marked as "Professional working")
- ❌ "Open to Work" not enabled when job-seeking
- ❌ 10+ projects including trivial learning exercises
- ❌ Broken links (Notion page that's empty, GitHub that's private)
- ❌ No contact information in About section
- ❌ Inconsistent with resume (different dates, titles, metrics)

## Recruiter Discoverability Audit

Check these factors that affect recruiter search visibility:

| Factor | Impact | How to Check |
|--------|--------|--------------|
| Headline keywords | 🔴 Critical | Search LinkedIn for your target role — do you appear? |
| About section keywords | 🔴 Critical | LinkedIn algorithm scans for keyword matches |
| Experience keywords | 🔴 Critical | Recruiters filter by skills mentioned in experience |
| Skills section | 🟡 High | Recruiters use skill filters in LinkedIn Recruiter |
| Certifications | 🟢 Medium | Appears in certification filters |
| Activity/posting | 🟡 Medium | Active profiles get more visibility |
| Recommendations | 🟢 Low | Social proof, not search ranking |

## Before/After Rewrite Template

**Weak About opening:**
> "I am a software engineer with a strong focus on software design, DevOps, clean code, and reliable architecture. Beyond the technical stack, I'm a quick learner who thrives on open communication and active listening."

**Strong About opening:**
```
Full-stack software engineer with 2+ years of experience building scalable 
microservices platforms at Gosoft (Thailand) and interning at Agoda. I specialize 
in modernizing legacy systems and delivering production-grade applications.

WHAT I DO:
• Architect and migrate legacy systems to modern stacks (Java Struts → Spring Boot 3)
• Build microservices platforms with NestJS, ReactJS, and Golang
• Implement GitOps deployment pipelines and observability solutions
• Mentor junior developers and drive Agile practices
```

**Why the rewrite works:**
- First 3 lines are keyword-rich (recruiters see these without clicking "see more")
- Opens with achievement and context (not "I am...")
- Includes specific companies (Gosoft, Agoda — brand signals)
- "WHAT I DO" section is scannable and specific
- Shows trajectory and specialization
