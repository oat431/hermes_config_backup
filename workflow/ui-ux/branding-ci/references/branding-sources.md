## Key numbers worth citing

- Signature color palette → up to ~80% brand-recognition boost
- 5–7 impressions before a customer remembers a brand
- Max 3–5 personality adjectives; 2–3 emotions; ~60/30/10 palette usage ratio
- WCAG AA contrast: ≥4.5:1 body text, ≥3:1 large text / UI components
