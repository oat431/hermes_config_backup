## Key Patterns for Broad Professions

### 1. Sub-Discipline Coverage
- When a profession has 6+ major sub-disciplines, give each 1-2 its own file rather than cramming
- Pair related disciplines in shared files when they share foundations (Mechanical+Industrial, Chemical+Environmental)
- Include an "Emerging Fields" file for growing specialties (robotics, aerospace, etc.)
- In the overview, list ALL fields with license requirements and primary industries

### 2. License Levels (Multi-Tier)
- Engineering has 3 license levels — include all in overview and university guide
- Some fields are "controlled" (must be licensed), others are not — call this out explicitly
- Washington Accord: mention international recognition of degree

### 3. TCAS — Science-Math Only
- Engineering REQUIRES science-math track (unlike law/teaching/psychology)
- TPAT 3 (engineering aptitude) is unique to this profession
- Math 1 + Physics + TPAT 3 = the "big three" for admission

### 4. EEC Context
- Eastern Economic Corridor is a massive engineering opportunity — worth its own section
- List specific EEC projects and which engineering disciplines they need

### 5. Salary by Field
- Engineering salaries vary significantly by discipline (software > petrochemical > civil)
- Include a field-by-field salary table (entry → mid-career → senior)
