## Key Grade-Band Introductions

### 11. Basic Algebra (พีชคณิต)
- **ป.1-3:** Number sentences with □ (e.g., 5 + □ = 8), fact families
- **ป.4-6:** One-step equations, variable as ตัวแปร, simple inequalities
- **ม.1:** Linear equations in one variable, properties of equality
- **ม.2:** Coordinate plane, graphing y = mx + c, slope
- **ม.3:** Linear systems (substitution, elimination), inequalities

### 12. Geometry Shapes (เรขาคณิต)
- **ป.1-3:** Identify 2D/3D shapes, sides, vertices, symmetry
- **ป.4-6:** Triangle types (by sides/angles), quadrilaterals, angles, protractor
- **ม.1:** Geometric constructions, angle/segment bisectors
- **ม.2:** Parallel lines + transversal, triangle congruence (SSS/SAS/ASA), Pythagorean Theorem
- **ม.3:** Similar triangles, circle geometry, tangent properties

### 13. Measurement (การวัด)
- **ป.1-3:** cm, m, km; g, kg; mL, L; time; money (บาท/สตางค์)
- **ป.4-6:** mm, mg, kL; metric conversions; 1 cm³ = 1 mL; perimeter as measurement
- **ม.1:** Thai traditional units (วา, ไร่, งาน), vernier calipers
- **ม.2:** Speed = distance/time, scale drawings/maps
- **ม.3:** Scientific notation, significant figures, precision vs accuracy

### 14. Area and Perimeter (พื้นที่และความยาวรอบรูป)
- **ป.1-3:** Count unit squares, perimeter by measuring all sides
- **ป.4-6:** Square/rectangle P and A; triangle A = ½bh; parallelogram, trapezoid, rhombus, kite; circle (C = 2πr, A = πr²); composite shapes
- **ม.1:** Complex composite shapes, regular polygons
- **ม.2:** Arc length L = (θ/360)×2πr, sector area
- **ม.3:** Applications (land area, floor plans), optimization, Thai land units

### 15. Volume and Surface Area (ปริมาตรและพื้นที่ผิว)
- **ป.1-3:** Compare containers, non-standard units, counting cubes
- **ป.4-6:** Rectangular prism: V = l×w×h; 1 m³ = 1,000,000 cm³
- **ม.1:** Cube, composite solids
- **ม.2:** Prisms (V = Bh), cylinders (V = πr²h, SA = 2πr² + 2πrh)
- **ม.3:** Pyramids (V = ⅓Bh), cones (V = ⅓πr²h), spheres (V = ⁴⁄₃πr³, SA = 4πr²)

### 16. Coordinate Plane (ระบบพิกัดฉาก)
- **ป.1-3:** Grid maps, location language (left/right/up/down)
- **ป.4-6:** Quadrant I only, ordered pairs (x,y), plotting
- **ม.1:** All 4 quadrants, translation, reflection
- **ม.2:** Linear graphs, slope m = (y₂-y₁)/(x₂-x₁), intercepts
- **ม.3:** Distance formula, midpoint formula, point-slope form

### 17. Sets (เซต)
- **ป.1-3:** Informal grouping/sorting activities
- **ป.4-6:** Venn diagrams (informal, 2-circle), Carroll diagrams
- **ม.1:** Set notation, elements (∈), empty set (∅), subsets, power set
- **ม.2:** Union (∪), intersection (∩), complement ('), difference, De Morgan's laws, Venn (2-3 sets)
- **ม.3:** Survey problems, set builder notation, n(A∪B) = n(A)+n(B)-n(A∩B)

### 18. Statistics (สถิติ)
- **ป.1-3:** Tally marks, pictographs (1 picture=1 unit), simple bar charts
- **ป.4-6:** Scaled pictographs, double bar charts, line graphs, pie charts, mean (x̄ = Σx/n)
- **ม.1:** Mean, median, mode, range, stem-and-leaf plots
- **ม.2:** Histograms, frequency polygons, cumulative frequency, box plots (quartiles, IQR)
- **ม.3:** Variance (σ²), standard deviation (σ), scatter plots, correlation

### 19. Probability (ความน่าจะเป็น)
- **ป.1-3:** Certain/possible/impossible, simple chance experiments
- **ป.4-6:** P(E) = favorable/total, probability scale 0-1, fair games
- **ม.1:** Sample space (S), events as subsets, P(E) = n(E)/n(S), complementary events
- **ม.2:** Tree diagrams, counting principle (m×n), independent events: P(A∩B)=P(A)×P(B), expected value
- **ม.3:** P(A∪B) = P(A)+P(B)-P(A∩B), conditional probability, two-way tables

### 20. Mathematical Processes (ทักษะและกระบวนการทางคณิตศาสตร์)
Integrated across ALL strands; 5 key skills:
1. **Problem Solving (การแก้ปัญหา):** Polya's 4 steps introduced ป.4-6
2. **Reasoning (การให้เหตุผล):** Inductive → deductive; geometric proofs ม.2-3
3. **Communication (การสื่อสาร):** Words→pictures→symbols→formal notation
4. **Connection (การเชื่อมโยง):** Within math, across subjects, daily life
5. **Creativity (ความคิดริเริ่มสร้างสรรค์):** Multiple solutions, original approaches

| Concept | Formula | Thai Name |
|---------|---------|-----------|
| Pythagorean Theorem | a² + b² = c² | ทฤษฎีบทพีทาโกรัส |
| Slope | m = (y₂-y₁)/(x₂-x₁) | ความชัน |
| Distance | d = √[(x₂-x₁)²+(y₂-y₁)²] | ระยะห่าง |
| Midpoint | ((x₁+x₂)/2, (y₁+y₂)/2) | จุดกึ่งกลาง |
| Circle area | A = πr² | พื้นที่วงกลม |
| Cylinder volume | V = πr²h | ปริมาตรทรงกระบอก |
| Pyramid volume | V = ⅓Bh | ปริมาตรพีระมิด |
| Sphere volume | V = ⁴⁄₃πr³ | ปริมาตรทรงกลม |
| Mean | x̄ = Σx/n | ค่าเฉลี่ยเลขคณิต |
| Standard deviation | σ = √[Σ(x-x̄)²/n] | ส่วนเบี่ยงเบนมาตรฐาน |

## Common Problem Types Per Area

- **11:** "สามเท่าของจำนวนหนึ่งลบด้วย 7 เท่ากับ 20" → 3x-7=20
- **12:** "สามเหลี่ยมมุมหนึ่ง 40° อีกมุมหนึ่ง 60° มุมที่สามเท่าไร"
- **13:** "รถวิ่ง 80 กม./ชม. 3 ชั่วโมง ได้ระยะทางเท่าไร"
- **14:** "สนามหญ้าพื้นที่ 240 ตร.ม. กว้าง 12 ม. ยาวเท่าไร"
- **15:** "ตู้ปลา 40×60×30 ซม. จุน้ำได้กี่ลิตร"
- **16:** "เส้นตรงผ่านจุด (1,2) และ (4,8) ความชันเท่าไร"
- **17:** "นักเรียน 40 คน ชอบคณิต 25 ชอบวิทย์ 20 ชอบทั้งสอง 10..."
- **18:** "คะแนนสอบ 5,8,6,9,7,8,5,4 หาค่าเฉลี่ย มัธยฐาน ฐานนิยม"
- **19:** "โยนลูกเต๋า 2 ลูก ผลรวมแต้มเป็น 7 ความน่าจะเป็นเท่าไร"
- **20:** Integrated — see Polya's steps: ทำความเข้าใจ→วางแผน→ดำเนินการ→ตรวจสอบ

## Cross-Connections

- **Algebra (11) ↔ Measurement (13):** Formulas as algebraic expressions
- **Geometry (12) ↔ Area/Perimeter (14):** Shape properties for area formulas
- **Area (14) ↔ Volume (15):** Base area × height concept, πr²
- **Coordinate (16) ↔ Algebra (11):** Graphing equations, solving systems
- **Sets (17) ↔ Probability (19):** Sample space = universal set, events = subsets
- **Statistics (18) ↔ Probability (19):** Data → probability estimates
- **Processes (20) ↔ ALL:** Problem-solving, reasoning, communication embedded across every strand
