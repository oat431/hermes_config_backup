## Key Patterns Observed

1. **Thai government domains (.go.th, .or.th) often block automated requests** — verify from a Thai browser
2. **University URLs vary in format** — some use `nurse.xxx.ac.th`, some use `nursing.xxx.ac.th`, some use `www.nurse.xxx.ac.th`
3. **TCAS exam weights change annually** — always mark with "⚠️ Verify annually"
4. **Professional council websites (สภา...) are the authoritative source** for licensing requirements
5. **Salary data is hard to verify** — mark as "Unverified" until user confirms from Thai sources
