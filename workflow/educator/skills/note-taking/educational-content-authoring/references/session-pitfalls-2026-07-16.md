# Session Pitfalls — 2026-07-16 (SWEBOK Vault Restructuring)

## Pitfalls Discovered

1. **Don't assume empty folders are unused.** Empty SWEBOK-numbered folders are roadmaps — they need overview files most. The overview IS the content for empty folders.

2. **Don't forget to cross-link between overview files.** Each KA's "Relationship to Other KAs" section should wikilink to adjacent chapters. This is what makes the vault navigable.

3. **When reviewing existing overviews, compare against the new template.** Older overviews may be stubs (under 20 lines) or personal bookmark lists. Flag these for rewrite alongside the new ones.

4. **Update the main index/Content file last.** It should reflect all changes — new folders, moved content, status indicators. This is the vault's table of contents.

5. **When the user has a multi-profile workflow (find books → summarize), produce checklists not notes.** The educator profile produces gap analysis and book lists; another profile produces the actual summaries. Don't create notes when the user wants a checklist.
