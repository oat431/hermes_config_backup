## The Seven มหาราช (Great Kings)

| King | Thai | Period |
|---|---|---|
| Ramkhamhaeng | พ่อขุนรามคำแหงมหาราช | Sukhothai |
| Naresuan | สมเด็จพระนเรศวรมหาราช | Ayutthaya |
| Narai | สมเด็จพระนารายณ์มหาราช | Ayutthaya |
| Taksin | สมเด็จพระเจ้าตากสินมหาราช | Thonburi |
| Rama I | พระบาทสมเด็จพระพุทธยอดฟ้าจุฬาโลกมหาราช | Rattanakosin |
| Rama V (Chulalongkorn) | พระบาทสมเด็จพระจุลจอมเกล้าเจ้าอยู่หัวมหาราช | Rattanakosin |
| Rama IX (Bhumibol) | พระบาทสมเด็จพระบรมชาติกาล | Rattanakosin |

## Mermaid Patterns for History

History strand uses heavy Mermaid usage:

- **Period timelines** → `flowchart LR` with chained periods
- **Dynasty trees** → `flowchart TD` with parent-child relationships
- **Event sequences** → `flowchart TD` showing causation chains
- **ASEAN expansion** → `flowchart LR` showing joining timeline
- **Historiography schools** → comparison tables (not Mermaid)
