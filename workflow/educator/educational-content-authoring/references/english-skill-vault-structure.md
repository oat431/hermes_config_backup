## Naming Convention

- Folders: `NN Section Name` (two-digit prefix)
- Files: `NN Title.md` (two-digit prefix matching teaching order)
- Sub-files: `NN.N Title.md` (e.g., `05.1 Present Simple.md`)

## Content Pattern

Every note includes:
1. YAML frontmatter (tags: topic, skill, context)
2. Clear heading + 1-2 sentence intro
3. Tables for structured content (not walls of text)
4. ❌/✅ examples showing wrong vs. right
5. "⚠️ Thai Speaker Traps" section (L1-interference errors)
6. Wikilinks to related notes
7. Sources section (Murphy, Swan, Coxhead, Cambridge/Barron's prep books)

## Index File Pattern

`English Skill Content.md` contains:
- Section headings with wikilinks + one-line descriptions
- Teaching Routes table (student profile → recommended path)
- Sources section with all referenced books
