# Phase Completion → Next Phase: Split-Session Pacing & Re-Confirmation Rules

Learned 2026-08-23 during the Phase 2 completion review and Phase 3 build. Supplements the "Phase Completion Review" section of SKILL.md.

## The pacing rule (user explicitly requested)

The completion review and the next phase's program design are often TWO separate conversations. The user said: "let do the review first but leave the workouts we will walk into phase 3 together after this."

- Do the review + all file updates first (review summary, program banner, baseline assessment, smart-scale finals, memory).
- Do NOT generate `phase_{N+1}` files during the completion review unless asked.
- When the user asks for the program, they will bring new constraints — gather them before writing a single file.

## Constraints to re-confirm at program creation (all changed between Phase 2 and 3)

1. **Equipment can change dramatically between phases.** Gym membership ended 2026-08-23 → Phase 3 is home-based (treadmill, 10 kg KB, 2 kg DBs, push-up/sit-up machines, mat). Barbell lifts became maintain-not-progress via a day-pass gym note with a 3-week no-gym rule. Never assume the next phase uses the same equipment.
2. **Schedule can change.** "Still unavailable Thu/Fri, that means Sunday is available" — Sunday flipped from rest to an easy-cardio training day. Always re-confirm available days; don't inherit the old schedule.
3. **Template-folder instruction.** The user may point at an external template folder ("create the phase 3 program by this template: F:\obsidian_note\oralita_md\templates\fitness") — read those templates and make live files conform (kcal column, run-log fields, etc.). The global Obsidian templates dir mirrors the vault's `template/` suite.
4. **Folder split requests.** User asked for `daily-workouts/gym/` and `daily-workouts/home/` — honor requested subfolder structures rather than imposing the previous layout.

## Use the clarify tool as the grill

The user will explicitly invite questions ("now you can use /grill-me"). Batch 3–5 independent questions in ONE clarify call (schedule role, gym frequency, equipment ambition, session length) with the recommended choice first — this is the fastest path to a complete spec.
