# Phase 2 Watch + Smart-Scale Review Reference

Use this reference when a current-phase review includes Xiaomi S400 and Xiaomi Watch S4 data.

## Standardized interpretation

- Compute the 7-day body-weight average from daily morning weights.
- Compare the current Sunday smart-scale reading with the prior Sunday reading, but treat one-week BIA changes as directional only.
- Do not convert a Monday-to-Sunday endpoint change directly into fat loss.
- Track fat mass, muscle mass, visceral-fat rating, and body-water percentage as trends. A small one-week muscle change is measurement noise unless it repeats across multiple standardized readings.

## Wearable data quality gates

- Steps/day: use for behavior feedback and gradual activity progression.
- PAI: 100/week is a long-term reference; do not add HIIT merely to hit it.
- Active calories: do not prescribe eating back wearable calorie estimates; wrist estimates are noisy.
- Resting HR: reject impossible/ambiguous values (e.g., 10.8 bpm), ask the user to verify the metric/unit, and make no decisions from it.
- During lifting, wrist optical HR is less reliable because of gripping; prioritize run/walk HR and resting-HR trends.

## Activity progression example

When actual steps are far below the long-term goal, ramp in stages:

- 3,500–3,600/day baseline → 5,000/day average next week.
- Use two 10-minute post-meal walks to close the gap.
- Move toward 6,000, then 8,000 only after the lower floor is repeatable.
- If programmed run/walk duration is exceeded, return to the prescribed dose. Use walking, cycling, or swimming for extra low-impact activity.

## Evidence anchors

- WHO adult guideline: 150–300 minutes/week of moderate activity is an eventual health target, not a reason to double a beginner's running dose in one session.
- Novice runners with obesity have elevated injury risk when initial running distance is too high; control starting running dose and build gradually. Search result used in the session: https://pmc.ncbi.nlm.nih.gov/articles/PMC6253747/
- PAI reference: NTNU CERG describes 100 PAI/week as the reference target and explains that PAI is earned from heart-rate elevation: https://www.ntnu.edu/cerg/personal-activity-intelligence
