# Shared Skills

This directory contains skills that are used across multiple profiles with identical implementations.

## Contents

**Identical across all profiles:**
- `yuanbao` - 15 profiles
- `hermes-desktop-plugins` - 15 profiles
- `slidev` - 6 profiles
- `obsidian-vault-maintenance` - 6 profiles
- `find-skills` - 5 profiles

**Main version (custom variants exist in some profiles):**
- `grill-me` - 7 profiles (ui-ux has custom version)
- `grill-with-docs` - 7 profiles (ui-ux has custom version)
- `obsidian-vault-builder` - 6 profiles (career-coach has custom version)

## Not Included

**`hermes-profile-setup`** - Kept in each profile because it has 4 different customized versions:
- hermes-main-profile
- book-summarizer
- career-coach
- data-engineer

## Usage

When a profile needs a shared skill, it should reference this directory rather than maintaining its own copy. Profile-specific customizations remain in `<profile>/skills/`.
